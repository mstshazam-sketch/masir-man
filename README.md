# مسیر من — اپ ثبت کارها برای اندروید

این پروژه یک اپلیکیشن اندروید بومی با Java و SQLite است. رابط کاربری فارسی و راست‌چین است و بدون اینترنت کار می‌کند.

## ساخت APK
1. پوشه پروژه را در Android Studio باز کنید.
2. صبر کنید Gradle Sync تمام شود (Android SDK 35 و JDK 17 لازم است).
3. از منوی Build > Build App Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
4. فایل app/build/outputs/apk/debug/app-debug.apk را به گوشی Samsung Galaxy A54 منتقل و نصب کنید.

داده‌ها در حافظه داخلی برنامه ذخیره می‌شوند. پاک‌کردن داده‌های برنامه یا حذف آن ممکن است باعث از دست رفتن کارها شود.

توجه: این بسته سورس‌کد است، نه APK ساخته‌شده. در محیط فعلی ابزار Android SDK/Gradle برای کامپایل و آزمون APK در دسترس نبود.
